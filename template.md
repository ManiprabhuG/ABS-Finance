# Printing Template Instructions for ABS Finance Management Software

## Objective

Create professional, clean, printer-friendly templates for all printable documents within the ABS Finance Management Software.

The templates must be:

* Easy to Read
* Professional Finance Layout
* Black & White Printer Friendly
* Color Printer Compatible
* A4 Paper Optimized
* PDF Export Ready
* Mobile Print Compatible
* Ink Efficient
* Suitable for Finance Companies
* Suitable for Audit and Legal Documentation

---

# Global Printing Standards

## Page Size

Use:

* A4 Portrait (Default)
* A4 Landscape (Reports Only)

---

## Margins

Top: 15mm

Bottom: 15mm

Left: 15mm

Right: 15mm

---

## Font Standards

Heading:

* 16px to 20px
* Bold

Sub Heading:

* 14px to 16px
* Semi Bold

Content:

* 11px to 12px

Table Content:

* 10px to 11px

All printable documents must support:

* PDF Download
* Print Preview
* Direct Print

* High Quality PDF Export

# Print Optimization Rules

Ensure:

* No UI Buttons in Print View
* No Navigation Bar
* No Sidebar
* No Unnecessary Colors
* Proper Page Breaks
* Repeating Table Headers
* Clean Borders
* Readable Fonts

---

# Final Requirement

Build reusable printing templates that automatically fetch live data from the selected record.

Every template must support:

* Print
* Preview
* PDF Download
* Professional Formatting
* Finance Industry Standards
* Audit-Friendly Layout
* Easy Readability

Do not use hardcoded sample data.

All print templates must dynamically load real database data from TiDB/MySQL through Prisma.
